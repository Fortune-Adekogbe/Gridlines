# Gridlines

This project tracks the power and energy generated by the Nigerian National Grid including frequency and voltage information. It also includes hourly power generation data from 24 power plants connected to the Grid. Specific dataset requests can be made by emailing fortunea@umich.edu.

## Dashboard
The Streamlit dashboard provides four views of the Nigerian grid. Overview shows generation and energy trends, Daily Explorer compares hourly profiles and station contributions, Power Plants compares observed output and reporting coverage, and Grid Conditions shows frequency and voltage reports.

Use the reporting interval controls to explore history. In Overview, All history follows the selected measurement: Energy uses the first and last available energy reports, while Generation uses the full archive. In Grid conditions, All history uses the first and last reports with frequency observations. The address bar preserves the active view, dates, comparison day, hour, and station selections for sharing. Missing daily power measurements are filled from accepted national hourly totals. Partial profiles produce observed daily peaks and off-peaks, with the accepted-hour count in their provenance. Missing or excluded 06:00 readings remain unavailable. Reporting times use West Africa Time.

The shared quality filter excludes the 106 audited extreme plant readings in [generation_exclusions.json](generation_exclusions.json) and their affected national totals before charts, summaries, or backfill. Each exclusion matches the original date, reporting hour, plant, and value, so source corrections can appear normally. Original readings remain available in a collapsed “Excluded readings” section below the charts. The database is unchanged. The [investigation](generation-anomaly-investigation.md) documents the evidence and the additional candidates that require review; weaker screening candidates are not automatically excluded.

Energy total cards use a shared MWh, GWh, or TWh scale appropriate to the selected interval. Their help icons show the precise MWh totals, and the cards wrap to fewer columns on smaller screens.

### Live Streamlit Dashboard
The live dashboard is avaliable at https://gridlines.streamlit.app/.

###  Local Streamlit Dashboard
The local streamlit dashboard can be created by following the following steps:

#### Clone the repository
```
git clone https://github.com/Fortune-Adekogbe/Gridlines.git
```

#### Install requirements via `pip`
```
pip install -r requirements.txt
```

#### Run the streamlit app
```
streamlit run app.py
```
